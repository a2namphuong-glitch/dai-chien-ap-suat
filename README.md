# Đại Chiến Áp Suất

Game đấu trường 4 người chơi trên trình duyệt, chủ đề **kỹ thuật viên hệ thống tưới tự động** (Đắk Lắk).
4 kỹ thuật viên phun nước hạ nhau, xen giữa là 5 "sự cố hệ thống" (câu hỏi hướng nghiệp): đúng thì nhận linh kiện nâng cấp, sai thì bị rò rỉ.

- Chạy: `node server.js` (không cần cài thư viện), mở `http://localhost:3000`
- Màn hình chiếu: thêm `/screen` vào cuối địa chỉ
- Sửa câu hỏi: `questions.json`
- Triển khai online: Render.com (file `render.yaml` có sẵn)
